02 / INPUT

构造入口

ZiweiBirth 与 ZiweiInput 是仅有的公开输入。两者在创建时完成校验，再转为只读的 NatalContext。

ZiweiBirth 性别、农历年序号、月、日、时；core 由年份推导年干支。
→
NatalContext 私有的统一上下文，不是第三种公开输入。
→
Natal 排盘完成后得到的不可变本命盘。
ZiweiInput 性别、生年干支、月、日、时；年柱须符合六十甲子。
→
NatalContext year = None；除绝对年份外，排盘规则与 ZiweiBirth 相同。
→
Natal 大限保留虚岁，所有 DecadeYear.year 均为 None。

输入范围

共同字段

  • month: 0..=11，正月为 0
  • day: 1..=30，初一为 1
  • hour: 0..=11，子时为 0

年份能力

  • ZiweiBirth.year + 124 必须可由 i32 表示
  • 历法转换、闰月与晚子时由 core 外层处理
  • Natal 的两个构造函数接收已验证输入，直接返回结果
03 / PIPELINE

排盘流程

两种入口都先转为 NatalContext，随后调用同一个 build_natal。管线只计算一次：结果不会回填输入，查询层也不重复排盘。

  1. 01

    归一化入口

    NatalContext

    create_from_birth 由年份推导年干支，并在上下文中保留 Some(year)；create_from_input 直接使用给定年干支，年份记为 None。

    调用 Natal 构造函数前，try_new 已完成范围或六十甲子校验。
  2. 02

    安命身，定宫干与五行局

    PalacePlacement[12]

    先定命宫、身宫落支和十二宫干，再由命宫与宫干定五行局。这些结果共同确定十二宫的宫名、地支与宫干。

    compute_ming_palace_branch / compute_shen_palace_branch → compute_palace_stems → bureau_from_ming_palace → compute_palace_placements
  3. 03

    安十八星

    Branch[18]

    日数与五行局安十四主星，月、时安左辅、右弼、文昌、文曲。合并两组结果后，每个 StarName 恰有一个落宫。

    compute_major_star_branches + compute_minor_star_branches → merge_star_branches
  4. 04

    记录星曜四化

    Star

    遍历 StarName::ALL，为每颗星计算生年四化与入、出自化，再按落宫地支归入 stars_by_branch。

    这些结果在排盘时写入 Star，查询时直接读取。
  5. 05

    装配十二宫

    Palace[12]

    按寅起环逐宫创建 Palace：写入宫名、地支、宫干和四条宫干飞化关系，再挂载落在该地支的星曜。

    build_palace_transformations → Palace::new
  6. 06

    解析坐标并排大限

    Decade[12]

    查出命宫、身宫、来因宫的宫名与地支，再根据性别、年干、年份、命宫和五行局生成大限方向及十二个大限。

    ZiweiInput 不含绝对年份，因此大限只保留虚岁，农历年均为 None。
  7. 07

    构造 Natal

    Natal::new

    Natal::new 接收出生上下文、生肖、十二宫、三组坐标、五行局、大限方向与十二个大限。

    构造后的 Natal 不可修改；core 也不提供半成品、builder 或结果注入入口。
排盘顺序不等于结果的所有权层级。 build_natal 按上述顺序计算，结果则按 Natal → Palace → Star / PalaceTransformation 组织。
04 / ROOT

Natal 根结构

Natal 保存由出生输入直接确定的本命盘结果。宫名与地支成对记录，因此命宫、身宫和来因宫都能定位到十二宫中的唯一宫位。

Natal ├─ context: NatalContext ├─ zodiac: Zodiac ├─ palaces: [Palace; 12] │ ├─ stars: Vec<Star> │ └─ transformations: [PalaceTransformation; 4] ├─ ming_palace_branch → PalaceName::Ming ├─ shen_palace_name + shen_palace_branch ├─ origin_palace_name + origin_palace_branch ├─ bureau: FiveElementBureau ├─ decade_direction: DecadeDirection └─ decades: [Decade; 12] └─ years: [DecadeYear; 10]
结果类型只能由 core 构造。 外部代码只能读取，不能直接创建或修改 Natal、Palace、Star、飞化关系或大限条目。

07 / HUA

四化所有权

A / B / C / D 是 core 中唯一的四化代码，外层再映射为禄、权、科、忌。来因宫宫干等于生年天干，因此它的四条飞化关系与四颗目标星上的生年四化一一对应。其他宫干飞化关系归源宫，自化归目标星。

A外层映射：禄
B外层映射：权
C外层映射：科
D外层映射：忌

生年四化

Star.origin_transformation

  • 全盘恰有四个 Some
  • A、B、C、D 各出现一次
  • 与来因宫的四条关系一一对应
  • 生年四化只随目标星保存

宫位关系

Palace.transformations

  • 每宫固定四条，顺序 A–D
  • 每条关系都记录源宫和目标宫的宫名、地支
  • star_name 可在目标宫中定位唯一星曜

自化

Star.self_transformations

  • 源支 = 目标支：outward
  • 源支与目标支相对：inward
  • 两者可同时存在，各自至多一个
PalaceTransformation { source_name: PalaceName, source_branch: Branch, transformation: Transformation, target_name: PalaceName, target_branch: Branch, star_name: StarName, }
08 / DECADE

大限与年份

出生输入可以直接确定十二个大限，因此它们随 Natal 保存。每限包含十个 DecadeYear，记录虚岁和可选农历年；core 不提前构造完整流年盘。

Decade { index: DecadeIndex, // 0..=11 ming_palace_branch: Branch, years: [DecadeYear; 10], } DecadeYear { year: Option<i32>, age: u8, // 虚岁 }

推进方向

  • 年干阴阳与性别相同：Forward
  • 不同：Reverse
  • 第 0 限命宫支等于本命命宫支

年份能力

  • create_from_birth：year = birth_year + age - 1
  • create_from_input：所有 year = None
  • 同一张盘不混用 Some 与 None
09 / API

公开读取面

ziwei facade 重导出稳定的公开 API。小型 Copy 值按值返回，数组和集合通过借用读取。

Rust · minimal usage
use ziwei::{create_from_birth, Gender, ZiweiBirth};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let birth = ZiweiBirth::try_new(
        Gender::Yang,
        1984,
        2,  // 三月，正月 = 0
        1,  // 初一
        4,  // 辰时，子时 = 0
    )?;
    let natal = create_from_birth(birth);

    for palace in natal.palaces() {
        println!("{:?} {:?}", palace.name(), palace.branch());
        for star in palace.stars() {
            println!("  {:?}", star.name());
        }
    }

    Ok(())
}

10 / SCOPE

边界与来源

ziwei_core 只负责把已验证输入构造成 Natal。条件查询、历法转换和展示由外层 crate 组合，避免改变 core 的存储模型。

ziwei_core 负责

  • 输入验证与统一计算流水线
  • 十二宫、十八星与五行局
  • 生年四化、宫位关系、自化
  • 生肖、大限方向与最小年份/虚岁
  • 保证 Natal、Palace、Star 之间的结构不变量

明确不负责

  • 按宫、星、年龄或年份条件查询
  • 完整流年宫位、星曜与四化盘
  • 公农历转换、时区、真太阳时
  • 简繁体与其他 i18n 文案
  • bindings、analysis、插件或规则集
