02 / INPUT

构造入口

ZiweiBirth 与 ZiweiInput 是仅有的公开输入。它们在边界完成校验，再归一化为只读 NatalContext。

ZiweiBirth 性别、年份、月、日、时；core 从年份推导年干支。
→
NatalContext 统一上下文；私有构造，不是第三种输入。
→
Natal 完整、不可变、只读的本命盘事实图。
ZiweiInput 性别、年干支、月、日、时；年干支必须组成六十甲子。
→
NatalContext year = None，但其余规则与出生年入口一致。
→
Natal 大限仍含虚岁；所有 DecadeYear.year 为 None。

输入范围

共同字段

  • month: 0..=11，正月为 0
  • day: 1..=30，初一为 1
  • hour: 0..=11，子时为 0

年份能力

  • ZiweiBirth.year + 124 必须可由 i32 表示
  • 历法、闰月、晚子时在 core 外消解
  • 验证成功后，两条 Natal 构造均无失败
03 / ROOT

Natal 根结构

Natal 只保存无需查询即可成立的固定事实。名字与地支成对保存，所有坐标都能解析到同一张盘中的唯一宫位。

Natal ├─ context: NatalContext ├─ zodiac: Zodiac ├─ palaces: [Palace; 12] │ ├─ stars: Vec<Star> │ └─ transformations: [PalaceTransformation; 4] ├─ ming_palace + ming_palace_branch ├─ shen_palace + shen_palace_branch ├─ origin_palace + origin_palace_branch ├─ bureau: FiveElementBureau ├─ decade_direction: DecadeDirection └─ decades: [Decade; 12] └─ years: [DecadeYear; 10]
不变量由类型系统与装配管线保证。 外部代码不能直接构造或修改 Natal、Palace、Star、关系边或大限条目。

05 / STAR

身份与落位

StarKey 是稳定身份；Star 是某张盘内的落位事实。分类与斗系属于 key，生年四化与自化属于落位对象。

  • 十四主星：Major
  • 左辅、右弼、文昌、文曲：Minor
  • 首批没有 Auxiliary 成员

  • StarKey::as_str() 返回 snake_case
  • 示例：ZiWei → "zi_wei"
  • 简繁体显示文案不在 core
06 / HUA

四化所有权

四化只使用稳定代码 A / B / C / D。生年天干与来因宫宫干一致，其飞出的四化同时表现为来因宫的四条关系和目标星的生年四化；其余宫位关系保存在源宫，自化保存在目标星。

A外层映射：禄
B外层映射：权
C外层映射：科
D外层映射：忌

生年四化

Star.origin_transformation

  • 全盘恰有四个 Some
  • A、B、C、D 各出现一次
  • 与来因宫的四条关系一一对应
  • 不再另存顶层数组

宫位关系

Palace.transformations

  • 每宫固定四条，顺序 A–D
  • 保存完整源宫与目标宫坐标
  • star_key 在目标宫唯一解析

自化

Star.self_transformations

  • 源支 = 目标支：outward
  • 源支与目标支相对：inward
  • 两者可同时存在，各自至多一个
PalaceTransformation { source_name: PalaceName, source_branch: Branch, transformation: Transformation, target_name: PalaceName, target_branch: Branch, star_key: StarKey, }
07 / DECADE

大限与年份

十二个大限是命盘固定事实，因此保存在 core。每限只保存十个“年份 + 虚岁”条目，不提前构造完整流年盘。

Decade { index: DecadeIndex, // 0..=11 ming_palace_branch: Branch, years: [DecadeYear; 10], } DecadeYear { year: Option<i32>, age: u8, // 虚岁 }

推进方向

  • 年干阴阳与性别相同：Forward
  • 不同：Reverse
  • 第 0 限命宫支等于本命命宫支

年份能力

  • from_birth：year = birth_year + age - 1
  • from_input：所有 year = None
  • 同一张盘不混用 Some 与 None
08 / API

公开读取面

使用 ziwei facade 即可获得稳定公开面。小型值按值返回，聚合数组与集合按借用返回。

Rust · minimal usage
use ziwei::{Gender, Natal, ZiweiBirth};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let birth = ZiweiBirth::try_new(
        Gender::Yang,
        1984,
        2,  // 三月，正月 = 0
        1,  // 初一
        4,  // 辰时，子时 = 0
    )?;
    let natal = Natal::from_birth(birth);

    for palace in natal.palaces() {
        println!("{:?} {:?}", palace.name(), palace.branch());
        for star in palace.stars() {
            println!("  {}", star.key().as_str());
        }
    }

    Ok(())
}

09 / SCOPE

边界与来源

core 的职责是构造可靠事实图，不是把所有消费方式都变成方法。查询与展示留在外层，避免反向污染存储结构。

ziwei_core 负责

  • 输入验证与统一计算流水线
  • 十二宫、十八星与五行局
  • 生年四化、宫位关系、自化
  • 生肖、大限方向与最小年份/虚岁
  • 维护结果图不变量

明确不负责

  • 按宫、星、年龄或年份条件查询
  • 完整流年宫位、星曜与四化盘
  • 公农历转换、时区、真太阳时
  • 简繁体与其他 i18n 文案
  • bindings、analysis、插件或规则集
