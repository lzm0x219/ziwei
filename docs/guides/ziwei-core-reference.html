设计原则

  • 一份本命真相源：Ziwei（Copy，构造期算完）
  • 视图只叠层：不重算星/宫干/飞边/生年四化
  • 禁止结果注入：测例不能预填命宫/紫微
  • 坐标分流：对内寅环，对外 Branch（子=0）

依赖方向

  • ziwei_binding → ziwei（单向）
  • 公开类型全部经 lib.rs re-export
  • 内部 placement / decade / palaces 不导出
  • 权威：ADR-0001…0008 + CONTEXT.md

2. 流程

双入口汇合到同一实现 from_validated_input，再跑安宫→安星→飞→大限。

2.1 入口与委托

from_birthZiweiBirth 年→干支组 Input
→
try_new校验月日时+六十甲子
→
from_validated_inputbirth_year=真实年
⇢
from_input代表年（仅时间线）

要点：排盘算法只在一处；from_birth 保留真实农历年给 years_in_decade；纯 from_input 用六十甲子代表年。

2.2 构造管线（Steps）

A安命·身（寅环 m±h）
→
B十二职逆布
→
C五虎遁宫干
→
D命宫纳音局
→
E–H紫微·天府·正曜·辅佐
→
Fly12×4 宫干飞
→
Decade十二步大限

2.3 查询时（不重建盘）

固定（本命）

  • 十二宫职/支/干、身宫
  • 十八星落宫
  • 来因、生年四化
  • 飞边集（48）、大限序列表

随 ZiweiView 变

  • Natal：本命职贴标；无 overlay
  • Decade { step }：大限命支起逆布职；层干四化
  • Annual { year }：太岁为命；年干四化

3. 如何使用

依赖 workspace 内 ziwei crate。历法消解完成后只传农历字段。

3.1 Cargo

[dependencies]
ziwei = { path = "crates/ziwei" }
# 或 workspace: ziwei = { workspace = true }

3.2 from_birth（推荐权威路径）

use ziwei::{
    Branch, Gender, PalaceRole, Ziwei, ZiweiBirth, ZiweiView,
};

let chart = Ziwei::from_birth(ZiweiBirth {
    gender: Gender::Yang, // 阳/男；阴 = Yin
    year: 1984,           // 农历年序号
    month: 2,             // 正月=0 → 三月=2
    day: 1,               // 初一=1
    hour: 4,              // 子时=0 → 辰时=4
})?;

// 三月辰时：命在子、身在申
assert_eq!(
    chart.branch_of_role(PalaceRole::Ming, ZiweiView::Natal),
    Some(Branch::Zi)
);
assert_eq!(chart.shen_branch(), Branch::Shen);

// 本命宫干与星
let ming = chart.palace_at(Branch::Zi);
let stars: Vec<_> = chart.stars_at(Branch::Zi).collect();
let laiyin = chart.laiyin_branch();
let year_hua = chart.year_transformations(); // [禄权科忌]

// 大限 / 流年视图
let step1 = chart.decade_steps()[1];
let decade_ming = chart.branch_of_role(
    PalaceRole::Ming,
    ZiweiView::Decade { step: 1 },
);
let annual_ming = chart.branch_of_role(
    PalaceRole::Ming,
    ZiweiView::Annual { year: 1990 },
); // 太岁 = 年支

// 飞宫
for fly in chart.palace_flies() {
    let _ = fly.self_transformation(); // Out | In | None
}

3.3 from_input（历法层已给年柱）

use ziwei::{Branch, Gender, Stem, Ziwei, ZiweiInput};

let input = ZiweiInput::try_new(
    Gender::Yang,
    Stem::Jia,
    Branch::Zi,
    2,  // 月
    1,  // 日
    4,  // 时
)?;
let chart = Ziwei::from_input(input)?;
// birth_year() 为甲子代表年（如 4），非历史公历/农历序号
// 宫盘与同柱 from_birth 一致；years_in_decade 绝对年可能不同

3.4 错误处理

use ziwei::ZiweiInputError;

match Ziwei::from_birth(birth) {
    Ok(chart) => { /* ... */ }
    Err(ZiweiInputError::MonthOutOfRange { value }) => { /* 0..=11 */ }
    Err(ZiweiInputError::DayOutOfRange { value }) => { /* 1..=30 */ }
    Err(ZiweiInputError::HourOutOfRange { value }) => { /* 0..=11 */ }
    Err(ZiweiInputError::InvalidYearPillar { .. }) => { /* 仅 from_input 路径 */ }
}

4. 公开 API

以下为 crate 根导出类型与主要方法。内部 placement / decade 等无公开步进函数。

4.1 构造

API说明
Ziwei::from_birth(ZiweiBirth) → Result<Ziwei, ZiweiInputError> 年序号→干支→委托实现；保留真实 birth_year
Ziwei::from_input(ZiweiInput) → Result<Ziwei, ZiweiInputError> 排盘实现主体；代表年作时间线锚
ZiweiInput::try_new(gender, stem, branch, month, day, hour) 校验月日时 + 六十甲子奇偶

4.2 本命查询

API说明
palace_at(Branch) → &Palace本命宫（role/branch/stem）
shen_branch() → Branch身宫叠支
shen_natal_role() → PalaceRole身落在本命何职
bureau() → FiveElementBureau命宫五行局
birth_stem() / birth_year() / gender()生年干、年序号、性别
stars_at(Branch) → impl Iterator<Star>该宫十八星

laiyin_branch() → Branch来因（年干表）
year_transformations() → [LayerTransformation; 4]生年禄权科忌+落宫
stem_transformations(Stem) → [LayerTransformation; 4]任意干层四化

4.3 大限 / 流年 / 视图

API说明
decade_steps() → &[DecadeStep; 12]十二步大限

with_view(view) → ZiweiHandle薄句柄，绑死当前 view

6. 坐标与 v1 边界

零点

  • Branch::index：子=0 … 亥=11（对外）
  • 寅环 yin0：寅=0（规则内部）
  • month：正月=0
  • hour：子时=0
  • day：初一=1

v1 不做

  • 引擎内公历/真太阳时
  • 杂曜全集、小限、批命文案
  • 多跳飞串、三爻变
  • 结果注入；NAPI 正式包（延后）

大限顺逆：年干阴阳与 Gender 同性顺、异性逆（阳男阴女顺）。起运虚岁=局数，每限 10 年。
