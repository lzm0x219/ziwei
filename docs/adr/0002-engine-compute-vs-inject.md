# 引擎必算 vs 预处理注入边界

双入口职责固定：`from_birth` 吃农历年序号权威资料；`from_input` 是历法层已给出年干支时的**原始量捷径**，不是第二套权威、也不是安星结果注入口。两入口在安宫、安星、四化、大限/流年、飞宫上**一律由引擎计算**。禁止把命宫、紫微、宫干、局数、星落、大限序列等排盘**结果**当作输入；否则黄金测例可被预填掏空。现有 `ZiweiInput` 的 `ming_palace_position` / `ziwei_star_position` 属迁移期废弃字段，目标形态为 `gender` + 年干支 + `month`/`day`/`hour`（零点与 ADR-0001 一致，并补 `day`）。

## Boundary table

| 量                       | `from_birth`    | `from_input`                | 规则                                   |
| ------------------------ | --------------- | --------------------------- | -------------------------------------- |
| 公历↔农历等历法换算      | 引擎外          | 引擎外                      | 禁止引擎内做                           |
| 闰月 / 晚子时 / 日界     | 调用方消解      | 调用方消解                  | 禁止引擎猜                             |
| `gender`                 | 输入            | 输入                        | 可注入（原始事实）                     |
| 年                       | `year` → 推干支 | `birth_stem`/`birth_branch` | 输入；表达不同                         |
| `month` / `day` / `hour` | 输入            | 输入                        | 可注入；`day` 为 `from_input` 目标必填 |
| 命宫、身宫               | **必算**        | **必算**                    | 禁止注入                               |
| 十二宫职                 | **必算**        | **必算**                    | 禁止注入整图为真相                     |
| 十二宫干、五行局         | **必算**        | **必算**                    | 禁止注入                               |
| 紫微及其余十七星         | **必算**        | **必算**                    | 禁止注入                               |
| 生年四化 / 层四化 / 飞宫 | **必算**        | **必算**                    | 禁止注入                               |
| 大限 / 流年序列          | **必算**        | **必算**                    | 禁止注入                               |

## Considered Options

- 允许无校验注入命宫+紫微 — 否决：测例可跳过 Step A/E，契约失真。
- 允许注入但与重算校验 — 否决：仍保留「结果型字段」心智；v1 选择更干净的原始量捷径。
- 取消 `from_input` — 保留：年干支已由历法层给出时不必再走 year 公式，与 `from_birth` 分工清楚。
