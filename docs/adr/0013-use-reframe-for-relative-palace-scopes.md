# 立极统一相对宫名 scope

`ziwei_query` 以立极作为相对宫名的唯一重定机制：选择一个已有本命宫作为命位起点，将十二个相对宫名映射到已有十二宫，不创建或改写 `Natal`、`Palace`、宫干、星曜和四化关系。一般立极查询直接选择起点；大限查询先选择 `Decade`，再以其大限命宫地支为起点使用同一立极关系，因此不另建一套大限宫名叠落算法。

本决策延续 [ADR-0003](0003-fly-edge-model.md) 与 [ADR-0004](0004-chart-query-api.md) 中 scope 只重映射宫职、不重算命盘事实的约束，但不恢复旧 `ZiweiView` API。`ReframeScope` 表达本命或任意立极，`DecadeScope` 以同一立极模型表达大限宫位坐标；年份定位结果 `DecadeYearSelection` 不是立极 scope。

立极形成完整的查询 scope，而不只是返回十二宫映射表。全部 L1 查询能力都可以在该 scope 中复用；按宫名导航时，宫名表示当前 scope 的相对宫名，宫位原有的本命宫名仍作为不可变事实明确可查。身宫与来因宫的实际宫位不随立极移动，但可以解析出它们在当前 scope 中对应的相对宫名。

同一实际宫位的相对宫名与本命宫名构成有方向的叠宫关系，表述为“当前 scope 某宫叠本命某宫”。任意立极 scope 都使用这一关系，大限只是以大限命宫为起点的立极，不另建大限专用叠宫模型。

立极后的宫线、三方、河图宫位与四正按相对宫名确定。对宫的底层地支位置关系不变，暗合宫始终按原地支确定。调用者在立极 scope 中查看这些关系时，只把关系中的已有宫位解析为该 scope 下的相对宫名。
