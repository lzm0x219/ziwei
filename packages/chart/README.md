# @ziweijs/chart

<!-- [![npm version][npmx-version-src]][npmx-href]

负责 [ziwei](https://github.com/lzm0x219/ziwei) 紫微斗数的标准命盘生成。

## 功能

- 统一命盘生成入口
- 编排 `calendar` 与 `core`
- 输出稳定的 `Chart` 结构
