# @ziweijs/calendar

<!-- [![npm version][npmx-version-src]][npmx-href]
[![npm downloads][npmx-downloads-src]][npmx-href] -->

负责 [ziwei](https://github.com/lzm0x219/ziwei) 的日期与历法的转换和归一化。

## 功能

- 历法转换：公历转农历、农历转公历、干支转公历、干支转农历
- 获取真太阳时
- 不同地区不同时段的夏令时处理
- 对农历的换年、换日的特殊处理
- 针对日期转换成斗数内部数据结构
